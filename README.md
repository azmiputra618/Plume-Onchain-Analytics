PLUME On-Chain Analytics

1. Project Overview
This project presents an on-chain data analysis of the PLUME protocol using Dune SQL. The analysis focuses on wallet activity, contract interactions, staking behavior, and protocol risk metrics to evaluate ecosystem health and user engagement patterns.

2. Objectives
- Identify the most active wallets interacting with WPLUME
- Analyze user behavior classification
- Evaluate staking and vault participation
- Assess protocol risk and contract deployment structure

3. Tools Used
- Dune Analytics (SQL)
- On-chain blockchain data

4. Queries Included
- Active Wallets interacting with WPLUME
- Activity User Analysis
- Address Contract Analysis
- Behavior Classification
- Protocol Risk Health Summary
- Staking & Vault Usage

5. Key Insights
- High transaction concentration among top wallets
- Long active-day distribution indicates sustained engagement
- Staking usage reflects strong participation within core holders
- Risk metrics suggest structural dependencies on key contracts

5. Data Source
All data extracted using Dune Analytics SQL queries.
